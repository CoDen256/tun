Rows are ingested from the gateway's rolling access log and deduplicated on time + path + client IP. Only /ota/bundle/<buildId>.js is tracked — current.json polls, /blob/* and /audio-manifest/* are not. There is no device identity and no account uid on these rows: the OTA token is shared and the gateway sees an IP. Anything that happened before this feature shipped is not in the log and will never appear.
